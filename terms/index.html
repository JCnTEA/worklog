一、隱私權政策

「勤務記錄系統」（以下稱本系統）是個人勤務紀錄工具。我們的設計原則是：資料預設只留在你自己的裝置，只有在你主動登入並按下備份時，才會上傳到你自己的 Google 雲端硬碟。

1. 蒐集哪些資料

  • 勤務紀錄：登記件數、時段、地點名稱、經緯度、店家名稱與距離等你自行輸入或由 GPS 取得的內容。
  • 裝置本機設定：主題、背景相片、介面偏好、版本與更新提示狀態。
  • 定位：僅在你按下定位時讀取，用於比對最近店家；不持續追蹤、不在背景記錄移動軌跡。

2. 資料存放位置

  • 上述資料存放在瀏覽器／App 的 本機儲存空間（localStorage），不會自動上傳到本系統的任何伺服器。
  • 本系統的網頁由 GitHub Pages 提供靜態檔案，沒有資料庫、也沒有接收紀錄的後端。

3. 我們不做的事

  • 不販售、不出租、不交換你的紀錄。
  • 不投放廣告、不做跨站追蹤、不埋第三方分析碼。
  • 不讀取你的通訊錄、相簿（除你主動選擇的背景相片）、簡訊或通話紀錄。

4. 你的控制權

  • 可隨時在帳號面板「匯出紀錄檔」帶走全部資料。
  • 清除瀏覽器資料、或解除安裝 App，即會刪除本機紀錄。
  • 雲端備份可自行在 Google 雲端硬碟的「Worklog」資料夾中刪除，或登出後停止使用。

二、Google 登入與雲端備份

使用的 Google 授權範圍

  • openid／email／profile：僅用來顯示「已登入的帳號」。
  • drive.file：只能存取本系統自己建立的檔案與「Worklog」資料夾，看不到你其他的檔案。

備份內容

一份 JSON 檔，放在「我的雲端硬碟 → Worklog → worklog-backup.json」，內含你的勤務紀錄與介面設定；你可自行開啟、下載或刪除，其他人（包含本系統作者）無法讀取。

撤回授權

可在 Google 帳號的第三方應用程式權限 頁面移除本系統，或在帳號面板按「登出」。

三、服務條款

使用本系統即表示你同意以下事項。

1. 服務性質

本系統為個人自行開發的勤務紀錄工具，非任何公司、政府機關或物流業者的官方系統；頁面內容與店家資料僅供參考。

2. 使用者的責任

  • 請自行確認紀錄內容正確；本系統不作為工時、薪資或稽核的唯一依據。
  • 請勿輸入他人個資、機密資訊或你不願備份到雲端的內容。
  • 共用裝置時，請自行登出或清除本機資料。

3. 資料與服務中斷

本系統為免費提供，可能因裝置、瀏覽器、網路、Google 服務或平台政策變動而中斷或改版；我們不保證資料永不失損，請定期使用「匯出紀錄檔」自行留存備份。

4. 智慧財產與第三方資源

店家名稱、地址與座標來自公開資料或官方門市查詢頁，權利屬原權利人；本系統僅作查找與距離比對之用。

5. 條款變更

條款如有調整會更新本頁並標註日期；繼續使用即視為接受更新後的內容。

6. 準據法

本條款依中華民國（台灣）法律解釋與適用。

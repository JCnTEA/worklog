# 勤務記錄系統 · 正式版 V0.10

每天登記「排障 / 會同」件數的小工具。純前端網頁，資料只存在自己這台裝置的瀏覽器裡；Android 包成 App，iOS 用瀏覽器開同一網址。

- 正式版：<https://jcntea.github.io/worklog/formal/>
- App 下載：<https://jcntea.github.io/worklog/apk/>

## 用途

上班時每做完一件排障或會同，就在對應時段按 `＋` 加一件；按錯了按 `－` 修正。整天下來件數、早／晚班分配、合計都自動算好，不用另外抄。

## 每日怎麼用

1. 打開網址或 App，確認頁面上方的日期與時段是不是今天、現在這一段。
2. 找到「排障」或「會同」，按 `＋` 累加件數，按 `－` 修正。
3. 一段結束按「保存目前時段」。
4. 下方「今日合計」自動累加「排障 合計」「會同 合計」。
5. 「近期日誌」看最近 7 天，每天一列（日期／排障／會同／合計）。

- 時段：半夜 00:00–07:59 也可登記，換時段（08:00、13:00、18:00）時會自動記下上一段。
- 每天從 0 開始，跨日不用手動清。
- 「重設今日件數」只在真的填錯整天時用。

## 出勤地點

- 「取得 GPS 位置」抓目前座標；或「貼座標」直接貼上。
- 「重新查詢附近」列出最近的蝦皮智取店、便利商店、超市、銀行等，點一間即套用到店名。
- 「複製座標」「清除座標」「套用」都是本機操作，不會上傳。

## 掃描待處理

遇到要記下但還沒處理的單，用「掃描」：選圖片／截圖或直接貼上文字 →「解析文字」→「加入待處理」，就會出現在「待排障 / 待會同」清單，之後再逐筆消掉。

- 拍紙本請正面、不反光、不要翻拍螢幕。

## 主題

頁首「主題」可換背景色或背景照片（可從相簿選擇、也可清除照片、回到預設）。字色會依背景深淺自動變深或變亮；用照片時會整體壓暗一層，確保字看得清楚。

## 資料存在哪

- 全部存在這台裝置的瀏覽器（localStorage），沒有伺服器、不會上傳。
- 換裝置、換瀏覽器或清除瀏覽資料就會消失，要留紀錄請用「下載截圖」。
- GPS 座標同樣只留在本機。

## App 與更新

| 平台 | 用法 |
| --- | --- |
| Android | 安裝正式版 APK（`worklog-1.0.apk`，versionCode 21，App 名稱「勤務日誌系統」） |
| iOS | 直接用瀏覽器開上面的正式版網址，功能一致 |

- App 每次啟動都會重新抓最新頁面（不快取），**不用換 APK 就會是最新版**。
- 有新版時頁面會自己重載一次；版本差距大才跳「版本過舊」，可選「下載更新」或「稍後」。
- 只有 App 本身（原生程式碼）改版才需要重新下載 APK；下載與安裝都在 App 內完成，不會外跳瀏覽器。
